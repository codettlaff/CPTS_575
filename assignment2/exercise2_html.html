2.a Variable Types

Identify which predictors are quantitative and which are qualitative.

library(tidyverse)

day_data <- read.csv(
  "data/bike+sharing+dataset/day.csv",
  sep = ","
)

hour_data <- read.csv(
  "data/bike+sharing+dataset/hour.csv",
  sep = ","
)

# Variables that are numerically encoded but represent categories
day_categorical <- c(
  "season", "yr", "mnth", "holiday",
  "weekday", "workingday", "weathersit"
)

hour_categorical <- c(
  "season", "yr", "mnth", "hr", "holiday",
  "weekday", "workingday", "weathersit"
)

# Quantitative variables: numeric variables that are not categorical
day_quantitative <- names(day_data)[
  sapply(day_data, is.numeric) &
  !(names(day_data) %in% day_categorical)
]

hour_quantitative <- names(hour_data)[
  sapply(hour_data, is.numeric) &
  !(names(hour_data) %in% hour_categorical)
]

# Qualitative variables: character/factor variables + numerically encoded categories
day_qualitative <- names(day_data)[
  sapply(day_data, function(x) is.character(x) | is.factor(x)) |
  names(day_data) %in% day_categorical
]

hour_qualitative <- names(hour_data)[
  sapply(hour_data, function(x) is.character(x) | is.factor(x)) |
  names(hour_data) %in% hour_categorical
]

head(day_data)
head(hour_data)

cat("Quantitative variables:\n")

cat("\n\nQualitative variables:\n")
cat(paste(day_qualitative, collapse = ", "))

cat("\n\n\nHOUR DATASET\n")

cat("\n\nQualitative variables:\n")
cat(paste(hour_qualitative, collapse = ", "))

We can automatically check the R storage type from the variable’s statistical type. If the data type is not numeric, then the variable is not quantitative. However, a qualitative (categorical) variable can still have a numeric data type. The season, year, month, holiday, weekday, workingday, and weathersit variables are all categorical, but stored as the integer data type. These variable types were hard-coded.

2.d Monthly Bike Rentals

Create a bar plot showing the total number of bike rentals for each month of the year.

# Calculate total bike rentals for each month
monthly_rentals <- day_data %>%
  mutate(month = format(as.Date(dteday), "%B")) %>%
  group_by(month) %>%
  summarise(total_rentals = sum(cnt)) %>%
  mutate(month = factor(month, levels = month.name))

2.e Relationships Among Variables

Using the dataset, investigate the relationships among the predictors. Focus the correlation matrix on quantitative predictors: temp, atemp, hum, and windspeed. The rental-count variables (casual, registered, cnt) are response variables rather than predictors. Avoid including variables such as season, weekday, weathersit because their categories are represented by numerical codes.

# Quantitative predictors
quantitative_predictors <- c(
  "temp",
  "atemp",
  "hum",

# Correlation matrix
correlation_matrix <- day_data %>%
